# Distribution playbook — which asset, when, where

Half the value of the template system is knowing which asset to make. This file routes
occasions to assets: fill the table as the media layer comes online, citing formats by their
`captures/{{CAPTURE_NAME}}/formats.json` ids and templates by archetype. Facts always come
from the brief (typed slots otherwise); captions are deliverables beside the canvas, not an
afterthought; and the system's content rules (the lock's content layer) apply to captions
exactly as to canvases.
