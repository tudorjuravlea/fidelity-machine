# Security policy

- **Supported versions:** the latest release only; older releases receive no fixes.
- **Reporting:** report vulnerabilities privately via GitHub private vulnerability
  reporting on this repository, or by email to tudor@juravlea.ro — never in
  a public issue or PR.
- **No secrets in issues:** never include tokens, credentials, client design-system
  material, or lock files from real systems in issues, PRs, or reports. Reproduce with the
  synthetic `acme-banking` fixture instead.
